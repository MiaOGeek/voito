# Deployment Notes (Hostinger)

## Restart the app without redeploying

If the site shows 503 after a deploy, Passenger may not have restarted. Run via SSH:

```bash
touch ~/domains/voito.info/public_html/tmp/restart.txt
```

## Environment

- **Hosting**: Hostinger (Phusion Passenger)
- **Node.js**: `/opt/alt/alt-nodejs22/root/bin/node` (v22)
- **App root**: `~/domains/voito.info/public_html/`
- **Build output**: Standalone (`output: "standalone"` via `NEXT_OUTPUT_MODE` env var)
- **Start file**: `server.js` (auto-generated by Next.js standalone build)

## Build process

Hostinger's Git deploy:
1. Clones repo to `.builds/source/`
2. Runs `npm install` (falls back to `--legacy-peer-deps` on conflicts)
3. Runs `npm run build`
4. Copies standalone output to `public_html/`
5. Passenger picks up `server.js`

## Troubleshooting

- **503 after deploy**: Run the restart command above
- **Build fails**: Check deploy logs in Hostinger panel or `.builds/logs/`
- **Manual server test via SSH**: `/opt/alt/alt-nodejs22/root/bin/node ~/domains/voito.info/public_html/server.js`
