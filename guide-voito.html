2. Deploiement (Hostinger)

Environnement

ElementValeur
HostingHostinger — Phusion Passenger
Node.js/opt/alt/alt-nodejs22/root/bin/node (v22)
App root~/domains/voito.info/public_html/
Build modeNext.js standalone (output: "standalone")
Entry pointserver.js (auto-genere par Next.js)
Base de donneesMySQL via Prisma — TiDB Cloud (distante, accessible depuis le PC local)

Processus de deploy

  1. Faire un git push sur la branche master
  2. Hostinger clone le repo dans .builds/source/
  3. Execute npm install (fallback --legacy-peer-deps)
  4. Execute npm run build
  5. Copie le build standalone dans public_html/
  6. Passenger demarre server.js

Redemarrer sans redeployer

touch ~/domains/voito.info/public_html/tmp/restart.txt

3. Contenu SEO des marques

Chaque marque (Brand) possede des champs SEO en base :

  • h2Top / descriptionTop — contenu au-dessus des annonces
  • h2Bottom / descriptionBottom — contenu en dessous
  • metaTitle / metaDesc — balises meta pour le SEO

Si ces champs sont NULL, la page s'affiche sans texte SEO (composant SeoContent retourne null).

6. Depannage

Erreur 503 apres deploy

touch ~/domains/voito.info/public_html/tmp/restart.txt

Build echoue

Verifier les logs dans le panel Hostinger ou dans .builds/logs/

Test manuel du serveur

/opt/alt/alt-nodejs22/root/bin/node ~/domains/voito.info/public_html/server.js

Page marque vide (pas de texte SEO)

  1. Verifier avec node scripts/list-brands.js — les marques avec "N" n'ont pas de contenu
  2. Ajouter l'entree dans scripts/seed-brands-seo.js
  3. Relancer node scripts/seed-brands-seo.js
